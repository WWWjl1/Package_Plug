# progress/ —— 学习进度（本机私有）

这个文件夹存放**你个人的**学习状态。里面由插件自动读写，一般不用手改。

> **它不会被上传到 GitHub。** 根目录的 `.gitignore` 把下面这几个 `.json` 排除了。
> 仓库里保留这个文件夹，是为了让别人下载后进度有地方存。

## 文件说明

| 文件 | 内容 | 什么时候生成 |
|---|---|---|
| `state.json` | 每个知识点的状态：`unseen` / `learning` / `mastered`，以及更新时间；复习记录 `reviewCount` / `reviewedAt` 也存在这里 | 第一次打开任意细分点时 |
| `quiz.json` | 小测作答流水 + 错题本（知识点 id → 题号数组） | 第一次答小测时 |
| `session.json` | 固定学习会话的 id（点侧栏入口时用来回到同一个会话） | 第一次点侧栏入口时 |
| `ui.json` | 界面状态，例如「是否进过学习界面」（用于隐藏提示条） | 第一次进学习界面时 |
| `time.json` | 学习时长：累计秒数、每天多少秒、每个知识点多少秒 | 第一次在学习界面停留超过 5 秒 |
| `backups/<时间戳>/` | 导入进度**之前**自动留下的旧进度副本 | 第一次使用「备份与导出 → 导入学习进度」时 |

## 学习时长是怎么算的

顶栏 **学习统计** 用的就是 `time.json`。计时规则刻意保守：

- **算**：学习界面在前台，而且最近 5 分钟内有鼠标/键盘/滚轮操作。
- **不算**：标签页切到后台、窗口最小化、超过 5 分钟没任何操作（走开了）、
  以及切走那一刻不足 5 秒的零头。

宁可少算，也不要把「窗口挂了一夜」当成学习时长——那种数字只会骗自己。
统计口径：**只在学习界面里计时**，切到原生对话界面问 AI 的那段时间不算在内。

- 连续天数：从今天往回数，某天不足 1 分钟就断。今天还没学不算断签（从昨天起算）。
- 时长按**本地日期**分桶，不用 UTC（否则北京时间凌晨那几小时会被算到前一天）。
- 单次心跳最多认 300 秒，防止一次异常把一天冲爆。

## 备份 / 迁移（界面里的「进度备份」）

顶栏的 **进度备份** 按钮可以做两件事：

- **导出为 JSON 文件**：把 `state.json` + `quiz.json` + `ui.json` 打包成一个文件下载下来。
  **不含 `session.json`** —— 会话 id 是这台机器上的，换台机器导进去只会是个失效指针。
- **从 JSON 文件导入**：覆盖当前进度。**覆盖前一定会先把现有进度备份到
  `progress/backups/<时间戳>/`**；如果连备份都写不成功，就拒绝导入（绝不先删后写）。
  坏数据整包拒掉、一个字都不写盘。

导错了的救法：进 `progress/backups/` 找到导入前那个时间戳文件夹，把里面的三个文件拷回
`progress/` 覆盖即可。

> `progress/backups/` 同样被 `.gitignore` 排除，不会上传。

## 「今日复习」是怎么算出来的

顶栏那颗 **今日复习** 用的就是上面两个文件，规则完全公开：

1. **有没消化的错题** → 不管隔了多久，直接进队列（错题是「没学会」的硬证据）。
   答对那道题后自动移出。
2. **在学，而且放了 3 天还没学完** → 催一下。
   （门槛是 3 天不是 1 天：打开一个知识点就会自动标成「在学」，所以「在学」只代表
   「我点开过」。门槛设 1 天的话，随便翻一翻就是几十条，队列立刻变噪音。）
3. **已掌握** → 按间隔阶梯 **1 / 3 / 7 / 16 / 35 天**，每点一次「复习过了」往上走一档，
   到 35 天封顶。

队列按「错题未消 > 还在学 > 已掌握到期」排序，同一档里拖得越久越靠前，一次最多列 25 条
（清掉上面的，剩下的自动顶上来）。

想重置某个知识点的复习节奏：把它在 `state.json` 里的 `reviewCount` 删掉即可（等于回到第一档）。

## 想清空进度重来

删掉 `state.json` 和 `quiz.json` 即可（不用重启，重新进一次学习界面就会重建）。

## 想换一个学习会话

改 `session.json` 里的 `sessionId`；或者直接删掉它，下次点侧栏入口会新建一个。

## 想重新下载一份干净进度

删掉这四个 `.json` 文件，用 `git checkout -- progress` 恢复成仓库里的初始状态（仓库里没有这几个文件，所以等于回到空白）。
