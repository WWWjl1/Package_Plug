# progress/ —— 学习进度（本机私有）

这个文件夹存放**你个人的**学习状态。里面由插件自动读写，一般不用手改。

> **它不会被上传到 GitHub。** 根目录的 `.gitignore` 把下面这几个 `.json` 排除了。
> 仓库里保留这个文件夹，是为了让别人下载后进度有地方存。

## 文件说明

| 文件 | 内容 | 什么时候生成 |
|---|---|---|
| `state.json` | 每个知识点的状态：`unseen` / `learning` / `mastered`，以及更新时间 | 第一次打开任意细分点时 |
| `quiz.json` | 小测作答流水 + 错题本（知识点 id → 题号数组） | 第一次答小测时 |
| `session.json` | 固定学习会话的 id（点侧栏入口时用来回到同一个会话） | 第一次点侧栏入口时 |
| `ui.json` | 界面状态，例如「是否进过学习界面」（用于隐藏提示条） | 第一次进学习界面时 |

## 想清空进度重来

删掉 `state.json` 和 `quiz.json` 即可（不用重启，重新进一次学习界面就会重建）。

## 想换一个学习会话

改 `session.json` 里的 `sessionId`；或者直接删掉它，下次点侧栏入口会新建一个。

## 想重新下载一份干净进度

删掉这四个 `.json` 文件，用 `git checkout -- progress` 恢复成仓库里的初始状态（仓库里没有这几个文件，所以等于回到空白）。
